# Spring Boot Third-Party API Fetching

A Spring Boot application that demonstrates how to consume third-party REST APIs using RestTemplate and expose the fetched data through REST endpoints.

## 🚀 Features

- Fetch data from third-party REST APIs
- Consume external APIs using RestTemplate
- Parse JSON responses
- RESTful API implementation
- Layered Architecture
- Exception Handling
- Clean and maintainable code

## 🛠️ Tech Stack

- Java 21
- Spring Boot
- RestTemplate
- Spring Web
- Maven
- Jackson JSON
- Postman

## 📁 Project Structure

```
src
 ├── controller
 ├── service
 ├── config
 ├── model
 └── resources
```

## 📌 Functionality

- Connects to external REST APIs
- Retrieves JSON data
- Converts responses into Java objects
- Returns processed data through custom REST endpoints

## ▶️ Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/madihaazamahmed-droid/springboot-thirdparty-api-fetching.git
   ```

2. Open the project in IntelliJ IDEA or Eclipse.

3. Build and run the application:
   ```bash
   mvn spring-boot:run
   ```

4. Test the API using Postman or a web browser.
